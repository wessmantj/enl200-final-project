# ENL200 Final Project — The Factory (Game)

Based on the novel *The Factory* by Hiroko Oyamada. A 2D top-down pixel art game built in Godot 4, styled after The Escapists. Three playable narrators, each with their own floor/zone and work loop, set inside a vast, surreal factory.

## Project Stack
- **Engine**: Godot 4
- **Art style**: 16×16 pixel art, Nearest filter, no antialiasing
- **Tile size**: 16×16
- **Sprite scale**: 4× in-engine (sprites are exported at 64×64)
- **Sprite source**: `sprites/` — generated by `generate_sprites.py` (run to regenerate)

## Repo Structure
```
sprites/
  characters/   — 3 playable characters (walk + work sheets, 4-dir)
  npcs/         — all NPCs (walk sheets, 4-dir)
  objects/      — shredder, desk, cabinet, TRAN cart, creatures, etc.
  items/        — red pen, documents, apron, ID badges, shred bag
  tilesets/     — floor, wall, moss tiles
escapist-sprites/  — source sprite sheets from The Escapists (reference)
generate_sprites.py — sprite pipeline (Pillow-based, run with python3)
README.md       — character profiles, NPC details, world elements
CLAUDE.md       — this file
```

## Build Roadmap

### Phase 1 — Godot Project Setup
- [ ] Initialize Godot 4 project, 2D renderer, pixel snap on
- [ ] Project settings: tile size 16×16, Nearest filter globally
- [ ] Import all `sprites/` with Nearest filter, no mipmaps
- [ ] Build `TileSet` resource from `sprites/tilesets/_sheet_tileset.png`
- [ ] Folder structure: `scenes/`, `scripts/`, `assets/`

### Phase 2 — Core Systems
- [ ] **Day/time system** — game clock, bell events at 8:55 / 9:00 / 12:00 / 12:55 / 1:00 / 5:30
- [ ] **Player controller** — 4-dir top-down movement, animation state machine (idle → walk → work)
- [ ] **NPC controller** — fixed patrol/idle routes, dialogue trigger on proximity
- [ ] **Camera** — follows player, clamped to room bounds
- [ ] **Dialogue system** — text box, character name, portrait, advances on input

### Phase 3 — Yoshiko's Level (Basement / Shredder Station)
- [ ] Design basement layout: shredder row (14 machines), TRAN delivery door, locker area, stairs, reception
- [ ] Shredder interaction loop: pick up container → feed pages → dispose full bag
- [ ] TRAN delivery event: triggers at 10am and 3pm, carts arrive at south door
- [ ] Machine states: idle / active / jammed (requires switching to next machine)
- [ ] NPCs: Captain Samukawa, Itsumi, Hanzake, the Giant — idle dialogue, "commercial" event
- [ ] Bell schedule drives day structure (morning meeting visible in background)
- [ ] Late-game: shredding rhythm hypnotic → screen distortion → Yoshiko becomes a black bird

### Phase 4 — Narrator's Level (Document Division Office)
- [ ] Design office layout: 4 desks with partitions, filing cabinet, return shelf, phone
- [ ] Proofreading loop: grab packet → read/mark errors (time-based or minigame) → return to shelf
- [ ] Sleep mechanic: idle too long → fade to black → wake up, time skipped, red pen marks on page
- [ ] NPCs: Kasumi, Irinoi (brownish perm), Glasses — whispered dialogue
- [ ] Discovery event: Narrator spots Yoshiko in the factory (cross-character moment)
- [ ] Narrator proofreads Hikaru Samukawa's fauna report (connects to Furufue's story)

### Phase 5 — Furufue's Level (Grounds + Live-in Lab)
- [ ] Outdoor grounds: Perlin noise layout of moss tiles, paths, buildings
- [ ] Lab interior: desk, microscope, backyard garden (shiso + tomatoes)
- [ ] Moss hunt mechanic: walk grounds, interact with moss tiles, log samples
- [ ] Family Moss Hunt event: spawn child NPCs, guided tour sequence, Forest Pantser warning
- [ ] Aoyama NPC: phone call events, logistics for hunt, the "15 years / what have you done?" scene
- [ ] Factory animals: factory shags by river (non-flying), coypus from drains
- [ ] Old man Samukawa + grandson Hikaru visit (connects to Narrator/Yoshiko arcs)

### Phase 6 — World Connections
- [ ] Shared factory map with bus stops connecting the three zones
- [ ] River / central bridge as shared explorable space
- [ ] Cross-character moments:
  - Yoshiko and Furufue meet at the Okinawan restaurant on the bridge
  - Narrator's proofread packet contains Hikaru's fauna report
  - Old man Samukawa = Captain Samukawa's father (implicit)
- [ ] Goto NPC appears in all three levels (connective tissue)

### Phase 7 — Polish
- [ ] Sound: shredder hum, bell chimes, rain ambience, machine noise
- [ ] Surreal late-game visuals: screen distortion, color desaturation, text fragments
- [ ] Main menu + character select screen
- [ ] Save/load system
- [ ] Ending sequences per character

## Implementation Notes
- Start with **Phase 3 (Yoshiko)** — her loop is the most mechanical and self-contained; best for prototyping core systems
- The day clock should be a singleton (autoload) so all three levels share it
- NPCs use a simple state machine: `IDLE → WALK_PATROL → DIALOGUE`
- Shredder machine is an `Area2D` with interaction prompt; tracks state via enum
- Moss tiles in Furufue's level are regular `TileMap` tiles with metadata (moss type, collected bool)
- The Perlin noise world gen for Furufue's grounds can use Godot's built-in `FastNoiseLite`
